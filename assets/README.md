SVG 素材说明

- `drum.svg`：击鼓唤醒游戏的鼓面按钮。
- `lion-head-sleep.svg`：游戏一未唤醒状态狮头。
- `lion-head-awake.svg`：游戏一完成后的点亮狮头。
- `eye-dotting-lion.svg`：游戏二点睛用正面狮头，文件注释中标出热点位置。
- `campus-fair.svg`：百团大战与社团招新场景。
- `sound-wave.svg`：锣鼓声、声波与吸引力视觉。
- `lion-cloth.svg`：进入狮被之下的章节视觉。
- `training-ground.svg`：训练场和夜晚训练章节视觉。
- `team-silhouette.svg`：集体、伙伴章节剪影视觉。
- `pattern.svg`：非遗纹样与文化内涵章节视觉。
- `paper-canvas.svg`：青春画卷结尾视觉。
- `share-poster.svg`：结尾分享海报草案。

音频接口预留在 `assets/audio/`。如需加入鼓声，可放置 `drum.mp3` 并在 `games/drumWake.js` 中接入，注意移动端音频必须由用户点击后播放。
